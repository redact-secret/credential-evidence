# Batch 2 carrier research, round 1: asana, box, airtable, dropbox

Issue: credential-evidence#235 (follow-up to the [Batch 2 table](batch-2-bounded-carriers.md) and its [Cases](batch-2-cases-a.md)).

This repository is maintained by the Redact Secret project, which also maintains the product, so none of this is independent validation. It records what nine provider pages, read raw on 2026-10-05, state about where each credential is carried. It does not change the Batch 2 table; the new dispositions below supersede the nine `carrier-unresolved` rows it lists. Each new Case is `maintainer-only`, a project-policy decision recorded by an AI agent on the owner's instruction (2026-10-05, [ADR 0020](../decisions/0020-solo-maintainer-period.md), queued for retro-review in #154), never `reviewed`. The provider-documented part is the carrier; value admission, span and attribution are project policy. No prefix, alphabet or width is claimed for any family, no subtype is inferred, and every fixture value is synthetic and untested against any service. The illustrative values printed on the provider pages are not format statements and were not copied.

All nine pages were readable. Each carrier was recorded as a new `provider-documented` claim appended in place to the family's draft contract revision 1 (claims only; no structure, open question or earlier claim was changed).

## Cases and fixtures

13 Cases (9 positive `must-flag`, 4 benign `must-not-flag`), 58 fixtures. Positive Cases are one per slot with three layouts each; the benign Case per provider covers the public client id or app key, documented and angle placeholders, environment or template references, masked displays, and non-secret outputs (Asana `x-asana-request-signature` is an HMAC output, not the secret). The Airtable Basic envelope follows the Figma precedent: the secret exists only inside the encoded credential, so the span is the whole encoded token. Fixtures are in `records/fixtures/{asana,airtable,dropbox,box}-authored.json`; `box-authored` is a new set, and its path was added to `.gitguardian.yaml` ignored-paths like the other authored sets.

## Left open (unchanged)

Prefix, alphabet, width and checksum of all nine credentials remain unstated and are still open questions in each contract. The Box open questions on app and developer tokens and downscoped tokens, refresh-token lifetime and rotation (the refresh guide states 60 days and single use; not yet recorded as a claim) and the one-secret-across-application-types question were not touched in this round.
